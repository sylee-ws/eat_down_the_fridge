## 남은 것

1. 실제 배포: 사용자가 Vercel에 올리고 환경 변수 입력.
2. 실제 AI 키로 회사별 한 번씩 돌려 보기 — 응답 스키마(null 허용 수량)와 기본 모델 이름이 실제로 통하는지.
3. 실제 폰에서 공유(카톡 나와의 채팅)·복사·룰렛 연출 확인.
4. 여러 레시피를 담아 부족 재료를 합치는 장바구니 누적.
5. 카카오 로그인 기반 '나에게 보내기' 직접 전송(카카오 개발자 앱 등록 필요).
6. 가족 간 설정 공유/기기 간 동기화 — 도입하면 기기 저장소 중심 구조에서 서버 저장으로 옮겨야 한다.
7. 요리 종류(한식/양식/중식) 선택.
8. 요리 완료 시 쓴 재료 자동 해제.
9. 공개 서비스로 바꿀 경우 사용량 제한·계정.
