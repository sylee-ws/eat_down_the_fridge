# 0006 다시 돌리기는 같은 판에서, 부족하면 1회 자동 보충

- **상황**: 룰렛 결과가 마음에 안 들 때의 동작과, 규칙 통과 후보가 적을 때의 동작을 정해야 했다.
- **결정**: 다시 돌리기는 같은 후보판에서 아직 안 나온 후보로만 돌린다(AI 호출 없음). 새 후보 받기는 이번 사용 중 판에 올랐던 요리명(최근 50개)을 피해서 요청한다. 서버는 통과 후보가 3개 미만이면 첫 응답 요리명을 피해 딱 한 번 더 요청해 채운다.
- **대안**:
  - 매번 새 후보 생성 — 다양하지만 느리고 비용이 든다.
  - 룰렛 후 목록에서 직접 고르기 — 룰렛의 재미가 줄어든다.
  - 보충 없이 적은 후보 그대로 — 1개면 룰렛이 사라진다.
- **결과**: 보충이 붙으면 요청 시간이 최대 두 배가 된다(전체 예산 50초, 남은 시간 15초 미만이면 보충 생략). 조건을 바꾸면 남은 후보가 재검사로 줄어들 수 있다.
