# 0004 카톡 전송은 폰 기본 공유창으로

- **상황**: 원래 아이디어는 "카카오톡 나에게 보내기 or 클립보드 복사".
- **결정**: 기기 기본 공유창(`navigator.share`)에 장바구니 문구를 넘기고, 사용자가 카톡 → 나와의 채팅을 고른다. 클립보드 복사는 항상 함께 제공. 공유창이 없는 기기(주로 PC)에서는 공유 버튼을 숨긴다.
- **대안**:
  - 카카오톡 공유(JS SDK) — 카카오 개발자 앱 등록·도메인 등록 필요.
  - 진짜 '나에게 보내기' API — 앱 등록 + 가족 각자 카카오 로그인 필요, 가장 무겁다.
- **결과**: 카카오 SDK·키·로그인 없음. 한 번 더 터치해야 한다(공유창에서 대상 선택). PC에서는 복사만 된다. 카카오 SDK를 넣어 "개선"하려면 사용자 결정이 필요하다.
