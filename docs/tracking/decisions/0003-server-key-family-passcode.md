# 0003 서버 보관 키 + 가족 공용 암호

- **상황**: 가족이 폰으로 쓰려면 인터넷에 올려야 하고, AI 호출에는 유료 키가 필요하다.
- **결정**: 키는 서버 환경 변수에만 두고, 가족 공용 암호 하나를 한 번 입력해야 AI를 쓸 수 있게 한다. 계정·사용량 제한은 두지 않는다.
- **대안**:
  - 서버 보관, 암호 없음 — 주소가 새면 비용 위험.
  - 각자 키를 앱에 입력 — 서버는 필요 없지만 가족마다 키 발급이 번거롭다.
  - 내 PC에서만 실행 — 폰·가족 사용 불가.
  - 계정 로그인 — 가족용에 과하다.
- **결과**: 암호를 아는 누구나 무제한 호출 가능(대입 방지·잠금 없음). 암호 교체는 환경 변수 변경 + 재배포이며, 가족 기기는 401을 받으면 저장 암호를 지우고 다시 묻는다. 공개 서비스로 바꾸려면 이 결정을 다시 해야 한다.
