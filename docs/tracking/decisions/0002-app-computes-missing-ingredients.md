# 0002 부족 재료는 앱이 계산한다

- **상황**: 원래 아이디어는 "AI가 부족 재료를 자동 분류"였다. 그런데 사용자는 보유 양념을 직접 체크하기로 했고, 즐겨찾기를 나중에 열면 "지금 냉장고 기준"으로 장바구니를 다시 계산하기로 했다.
- **결정**: AI에게는 재료 전체 목록만 받고, 부족 재료는 가진 것(선택 재료 ∪ 체크 양념 ∪ 물)과 이름을 정규화해 비교하는 한 함수가 계산한다. AI에게는 사용자 재료를 쓸 때 사용자가 쓴 이름을 그대로 쓰라고 지시한다.
- **대안**: AI가 부족 여부를 표시 — 즐겨찾기 재계산·조건 변경 재검사 때마다 AI를 다시 불러야 하고, 결과가 호출마다 달라진다.
- **결과**: 결과·즐겨찾기·재검사·서버 검사가 항상 같은 답을 낸다. AI가 이름을 바꿔 쓰면("대파" → "파") 가진 재료도 부족으로 잡힌다 — 이름 일치는 프롬프트 지시에 의존한다.
