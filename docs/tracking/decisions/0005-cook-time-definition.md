# 0005 15분은 불 사용 시간, 손질은 따로 10분

- **상황**: "15분 컷 레시피"의 15분이 무엇을 포함하는지 정해야 했다.
- **결정**: 15분 제한은 불(가열) 사용 시간에만 적용한다(사용자 선택). 재우기·해동처럼 오래 걸리는 레시피를 막으려고 손질 시간은 별도로 10분 이내로 제한하고 둘 다 표시한다.
- **대안**: 손질 + 조리 전체 15분 — 추천안이었으나 사용자가 고르지 않았다.
- **결과**: 최악의 경우 전체 25분짜리 레시피가 나올 수 있다. 두 값을 하나로 합치거나 손질 제한을 없애면 사용자 의도와 달라진다.
