# 0001 AI 회사를 설정값으로 골라 쓴다

- **상황**: 처음엔 Claude Haiku 4.5 하나로 정했지만, 사용자가 다른 회사 키(특히 Gemini)도 쓸 수 있기를 원했다.
- **결정**: Anthropic·Google·OpenAI 세 회사 연결부를 같은 모양(`AiProvider`)으로 만들고 `AI_PROVIDER` 환경 변수로 고른다(기본 anthropic). 모델은 `AI_MODEL`로 바꿀 수 있다. 검사·보충·오류 처리는 회사와 무관하게 같다.
- **대안**:
  - Claude 하나로 고정 — 가장 단순하지만 다른 키를 가진 사용자가 못 쓴다.
  - Gemini 하나로 교체 — 나중에 또 바꾸려면 코드 수정이 필요하다.
- **결과**: SDK 세 개 의존, 회사별 연결부·테스트 유지 비용. 응답 스키마 하나를 세 회사가 같이 쓰므로 가장 엄격한 OpenAI strict 규칙(모든 속성 required)에 맞춰야 한다. 회사를 바꿔도 화면·검사 코드는 바뀌지 않는다. 다시 한 회사로 고정하지 않는다.
